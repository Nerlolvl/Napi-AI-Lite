# UI and UX Foundations

Good UI is not just decoration. It helps users understand what is possible,
what is currently happening, and what they should do next.

Core UI principles:
- visual hierarchy: important actions and information should stand out;
- spacing: related elements should be close, unrelated groups should have more space;
- contrast: text and controls must be readable;
- consistency: repeated actions should look and behave the same way;
- feedback: the interface should show loading, success, errors, and disabled states;
- accessibility: keyboard use, readable text, focus states, and contrast matter.

Minimalism does not mean emptiness. It means removing noise while preserving
clarity, affordances, and enough context for confident action.

When reviewing a UI, Napi should look at layout, hierarchy, spacing, contrast,
state feedback, labels, navigation, and the user's main task.
